# MAX Chat на GREEN-API

Тестовое задание «Фронтенд-разработчик React»: простой веб-интерфейс для отправки и получения текстовых сообщений в мессенджере **MAX** через сервис [GREEN-API](https://green-api.com/max). Внешний вид — по мотивам [web.max.ru](https://web.max.ru/).

> **Про мессенджер.** В личном кабинете GREEN-API тариф для MAX недоступен (есть только WhatsApp и Telegram), поэтому, как разрешает задание, работа проверена на инстансе **WhatsApp**. Методы `sendMessage`, `receiveNotification` и `deleteNotification` у GREEN-API одинаковые для MAX и WhatsApp, так что приложение работает с обоими: достаточно указать данные нужного инстанса.

## Возможности

- Вход по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`, при необходимости `apiUrl`). Данные проверяются методом `getStateInstance`: войти можно только в авторизованный инстанс.
- Создание нового чата по номеру телефона получателя.
- Отправка текстовых сообщений — метод [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/).
- Получение ответов — [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/): long polling `ReceiveNotification` (таймаут 20 с), затем `DeleteNotification` для каждого уведомления.
- Статусы отправки, повторная отправка при ошибке, счётчик непрочитанных, разделители по дням.
- История чатов и данные входа хранятся в `localStorage`, поэтому переживают перезагрузку страницы.
- Адаптивная вёрстка (на телефоне видно либо список чатов, либо переписку) и тёмная тема по системной настройке.

## Стек

React 19, TypeScript, Vite. Сторонних зависимостей в рантайме нет: запросы к GREEN-API идут из браузера через `fetch` (API отдаёт CORS-заголовки), бэкенд не нужен.

## Запуск локально

Нужен Node.js 20+.

```bash
git clone https://github.com/alishangit/green-api-max-chat.git
cd green-api-max-chat
npm install
npm run dev
```

Откройте http://localhost:5173.

Сборка для продакшена: `npm run build` (результат в `dist/`), просмотр сборки: `npm run preview`.

## Подготовка инстанса GREEN-API

1. Зарегистрируйтесь в [личном кабинете](https://console.green-api.com/), создайте инстанс (MAX или WhatsApp: Developer) и авторизуйте его по QR-коду.
2. Скопируйте `apiUrl` (например, `https://7107.api.greenapi.com`), `idInstance` и `apiTokenInstance` со страницы инстанса.
3. В разделе «Уведомления» настроек инстанса:
   - «Адрес отправки уведомлений (URL)» оставьте **пустым**, иначе уведомления уходят на вебхук, а не в очередь HTTP API;
   - включите «Получать уведомления о входящих сообщениях и файлах»;
   - по желанию включите «…о сообщениях, отправленных с телефона», чтобы они тоже отображались в чате.

## Как проверить

1. Войдите с данными инстанса.
2. Нажмите «+», введите номер получателя (например, `79991234567`) — создастся чат.
3. Отправьте сообщение — оно придёт получателю в мессенджере.
4. Ответьте с телефона получателя — ответ появится в чате через несколько секунд.

## Как устроено

```
src/
  api/greenApi.ts           запросы к GREEN-API и типы уведомлений
  hooks/useNotifications.ts цикл ReceiveNotification -> обработка -> DeleteNotification
  lib/chatsReducer.ts       состояние чатов: создание, отправка, разбор входящих
  lib/phone.ts              нормализация и форматирование номера
  lib/storage.ts            чтение и запись localStorage
  components/               LoginForm, Sidebar, NewChatForm, ChatWindow, Avatar
```

Чат создаётся по номеру телефона, и первое сообщение уходит на `chatId = <номер>@c.us`. Во входящих уведомлениях MAX присылает свой `chatId` (например, `10000000`) и `senderPhoneNumber`. По номеру ответ привязывается к нужному чату, а полученный `chatId` запоминается и используется для следующих отправок. Сообщения от незнакомых номеров создают новый чат.

## Ограничения

- Только текстовые сообщения (`textMessage`, `extendedTextMessage`); остальные уведомления удаляются из очереди без показа.
- История хранится только в браузере. Сообщения, отправленные до первого входа, не подгружаются.
- `apiTokenInstance` хранится в `localStorage` — для тестового стенда это допустимо; кнопка «Выйти» удаляет его.
